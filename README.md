## 3. Configurable Contact Destination

The project includes an enquiry workflow compliant with configurable agency destinations:
- `VITE_AGENCY_EMAIL`: Target email address for client enquiries (triggers pre-filled `mailto:`).
- `VITE_AGENCY_WHATSAPP`: Target WhatsApp phone number (triggers pre-filled `wa.me/` message).
- If unconfigured, the UI clearly displays configuration guidance and provides a one-click **"Copy Brief to Clipboard"** button so no client enquiry details are ever lost.

## 4. Local Setup & Running Instructions

### Prerequisites
- Node.js 18+ or 20+
- npm

### Installation & Development
```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build
```
